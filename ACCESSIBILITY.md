# Mobilex Accessibility Baseline

Mobilex uses semantic landmarks, visible focus states, a skip link, a route announcer, reduced-motion handling, keyboard-friendly dialogs and command navigation, and responsive touch targets.

Before release:

- Keyboard-tab through navigation, dialogs, filters and checkout.
- Verify focus never disappears behind overlays.
- Test reduced motion mode.
- Test RTL and LTR.
- Confirm meaningful images have alt text.
- Confirm status is not communicated by color alone.
- Verify forms expose labels and errors.
