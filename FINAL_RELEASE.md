# Mobilex 2.0 — FINAL RELEASE

This repository is the cumulative Mobilex 2.0 release through Phase 10.

The product is feature-complete at the application architecture level, with storefront, commerce, account, orders, notifications, admin, growth, PWA, SEO, accessibility, security and release tooling included.

Live payment acceptance is intentionally provider-neutral until real gateway credentials and its documented API/signature contract are supplied. Do not accept real payments until the provider adapter has been configured and verified in staging.
